# Autonomous Drone Mission — «Облёт полигона»

Автономная миссия облёта полигона дронами, поиска «огоньков» на снимках и тушения наземным ровером. Вся логика управляется AI-агентами — один промпт запускает полный цикл.

## Как запустить

Весь проект управляется **одним промптом**. Отправь содержимое файла [`prompts/architect_agent.md`](prompts/architect_agent.md) в агентную систему (Zoo Code / OpenCode) — Архитектор сам разберёт конфиг, выберет дронов, параллельно запустит облёт, check-циклы, детекцию и ровер.

```bash
# Отправь содержимое файла как промпт агенту:
cat prompts/architect_agent.md
```

Никаких дополнительных скриптов запуска не нужно — агент сам вызывает все команды по шагам из промпта.

## config.json — конфигурация миссии

```json
{
  "drones": [
    { "id": 1, "ip": "192.168.1.116", "role": "survey" },
    { "id": 2, "ip": "192.168.1.111", "role": "takeoff_land" }
  ],
  "rover": {
    "ip": "192.168.1.200",
    "script_path": "/home/sverk/rover_control/move.py",
    "signal_script_path": "/home/sverk/rover_control/signal.py",
    "tower": { "x": 0.0, "y": 0.0 }
  },
  "flight": {
    "altitude": 2,
    "grid": "4x4",
    "cell_size": 0.8,
    "traverse": "snake"
  }
}
```

| Поле | Описание |
|------|----------|
| `drones` | Список дронов. Ровно один `"survey"`, остальные `"takeoff_land"` |
| `rover` | Наземный ровер (опционально). `tower` — координаты водонапорной башни |
| `flight.altitude` | Высота полёта в метрах |
| `flight.grid` | Размер сетки (`"NxN"`, например `"4x4"`) |
| `flight.cell_size` | Размер ячейки в метрах |
| `flight.traverse` | Схема обхода: `"snake"` (змейка) |

После детекции огоньков в конфиг добавляется секция:
```json
"detected_fires": [
  { "cell": "cell_2_2", "x": 0.4, "y": 0.4, "red_ratio": 0.023, "image": "cell_2_2__x0.4_y0.4.jpg" }
]
```

## drone_comand/ — низкоуровневые скрипты

Все скрипты работают через **SSH** (`sshpass -p sverk`) к дрону/роверу и используют ROS2-пакет `sverk_interfaces`. Каждый скрипт **блокирующий** — не возвращает управление, пока действие не завершено.

| Скрипт | Команда | Описание |
|--------|---------|----------|
| `takeoff.py` | `python3 takeoff.py <ip> [alt_m]` | Взлёт в body-кадре (по умолчанию 1.5 м) |
| `move.py` | `python3 move.py <ip> <x> <y> [alt_m]` | Полёт в точку (aruco_map). Timeout 30 с, точность 0.3 м |
| `land.py` | `python3 land.py <ip>` | Посадка |
| `save_img.py` | `python3 save_img.py <ip> [filename]` | Снимок с камеры + скачивание в `img/` через scp |
| `telemetry.py` | `python3 telemetry.py <ip>` | Текущие координаты дрона (x, y, z) |
| `rover_move.py` | `python3 rover_move.py <ip> <x> <y> [--script-path]` | Движение ровера в точку |
| `rover_signal.py` | `python3 rover_signal.py <ip> [--script-path]` | LED-сигналы ровера |

> **Важно:** `takeoff` использует **body-кадр** (аварийный подскок), `move` использует **aruco_map**. После взлёта нужно ~3 секунды на захват ArUco-маркеров.

### Пример ручного облёта

```bash
# Взлёт
python3 drone_comand/takeoff.py 192.168.1.111 1.5

# Облёт ячеек с фото
python3 drone_comand/move.py 192.168.1.111 0.0 0.0 1.5
python3 drone_comand/save_img.py 192.168.1.111 cell_0_0.jpg

python3 drone_comand/move.py 192.168.1.111 1.6 0.0 1.5
python3 drone_comand/save_img.py 192.168.1.111 cell_1_0.jpg

# Посадка
python3 drone_comand/land.py 192.168.1.111
```

## mission_scripts/ — готовые скрипты (альтернатива агенту)

Эти скрипты можно запустить напрямую **без AI-агента**.

### survey_grid.py

Полный облёт сетки N×N змейкой:

```bash
python3 mission_scripts/survey_grid.py <ip> <altitude> <N> <cell_size>
# пример:
python3 mission_scripts/survey_grid.py 192.168.1.111 1.5 4 0.8
```

Логика: взлёт (2 попытки) → облёт ячеек (move + sleep 1s + photo + sleep 0.5s) → посадка (2 попытки). При любой ошибке — аварийная посадка. Коды возврата: 0 = все фото, 2 = частично, 3 = посадка не удалась.

### check_drone.py

Check-цикл для одного дрона (взлёт → телеметрия → фото → посадка):

```bash
python3 mission_scripts/check_drone.py <ip> <drone_id>
# пример:
python3 mission_scripts/check_drone.py 192.168.1.112 2
```

Координаты из телеметрии встраиваются в имя файла: `drone_2_check__x1.44_y-1.01_z2.00.jpg`.

### fire_detector.py

CV-детектор огоньков на основе PIL/Pillow:

```bash
python3 mission_scripts/fire_detector.py [--img-dir <путь>] [--config <путь>]
# пример (значения по умолчанию):
python3 mission_scripts/fire_detector.py
```

Анализирует все `cell_*.jpg` в `drone_comand/img/`, ищет красные пиксели (R > 180, G < 100, B < 100) в центральных 40% кадра. Если доля красных пикселей > 1% — фиксирует огонёк. Результат записывается в `config.json` → `detected_fires`.

## prompts/ — AI-агенты

### architect_agent.md — главный оркестратор

Это **основной файл для запуска**. Отправляется как промпт агенту Zoo Code / OpenCode. Содержит 7 шагов:

| Шаг | Действие |
|-----|----------|
| 0 | Прочитать `config.json` |
| 1 | Пропинговать все дроны (и ровер) — `ping -c 2 -W 2 <ip>` |
| 2 | Выбрать survey-дрон с учётом результатов пинга, вывести обоснование |
| 3 | Вычислить координаты сетки (змейка), сформировать задания для всех агентов |
| 4 | Параллельно запустить Task-агентов: survey, check-дроны, ровер |
| 5 | Собрать результаты в финальный отчёт |
| 6 | Детекция огоньков: VLM-агент или fallback-скрипт `fire_detector.py` |
| 7 | Миссия ровера: башня → огоньки → башня (тушение) |

**Главный принцип:** ошибка одного дрона не останавливает всю миссию. Всегда собирается максимум результатов.

### script_builder_agent.md

Генерирует Python-скрипты облёта по плану от Архитектора. Использует шаблон с `emergency_land()` и явной передачей высоты в каждом вызове.

### fire_detector_agent.md

VLM-агент на базе `gemma4-vlm`. Анализирует снимки визуально, ищет красные точки/фигурки в центре кадра, записывает результат в `config.json`.

## Требования

- **Дроны:** PX4 + ROS2 Humble + пакет `sverk_interfaces`, ArUco-маркеры на полигоне
- **Ровер:** скрипты управления на борту (пути задаются в конфиге)
- **Доступ:** SSH (`sshpass`) ко всем устройствам
- **Python 3.8+** на хосте (откуда запускается агент)
- **Pillow** для CV-детектора (`pip install Pillow`)
- **Агентная система:** Zoo Code / OpenCode (или любая другая, умеющая запускать Task-агентов)

## Безопасность

- При любой ошибке навигации — **экстренная посадка** (emergency land)
- Взлёт и посадка с повторными попытками (по 2)
- Фото не сохранилось — миссия продолжается, ошибка логируется
- Дрон недоступен — пропускается, миссия продолжается с остальными
